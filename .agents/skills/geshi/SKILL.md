# 毕业论文格式规范与学术写作排版技能指南 (/geshi)

本技能为工科硕士毕业论文撰写与排版的全流程工程化标准，深度融合了实际撰写与修改中的严苛纠错经验（包括 `（1）` 与 `（2）` 编号使用场景限定、整段凝聚性杜绝碎片化、本章小结单段化、图片规范编号与专属目录归档、图框防溢出、分组柱状图防重叠、横向并排双图严格对称、公式段落紧凑化排版、正文半角空格清理与 6 轴 IMU 硬件真实性原则）。在撰写或修改后续各章节时，必须无条件严格执行本指南。

## 1. 段落结构、编号规范与学术凝聚性 (Paragraph & Numbering Standards)

### 1.1 `（1）` 与 `（2）` 编号的严苛使用场景
- **唯一允许场景**：`（1）`、`（2）` **仅允许在三级标题下**（如 2.3.2、3.2.1 等），在该三级标题**内容较多、较重要的情况下，用于对该小节进行宏观核心大技术模块的分割攥写**：
  - `（1）内容主要攥写该三级标题下的xxx部分：……`
  - `（2）内容主要攥写该三级标题下的xxx部分：……`
  - 以此类推。
- **全篇其余位置绝对严禁出现 `（1）`、`（2）` 符号**：
  - 除上述特定三级标题大模块拆分外，在各章引言、背景阐述、理由论述、图表分析、公式说明、以及各章小结等正文中，**一律严禁出现 `（1）`、`（2）`、`（3）` 等标号符号**。
- **整段凝聚性原则（杜绝碎片化）**：
  - **能够用一整段进行攥写的，绝对不要拆成几段或单句小列表攥写**！
  - 严禁将本来连贯的学术逻辑（如多项依据、多步特征、多个子相位定义）拆成一句话一行的小段落。
  - 段内应依托严谨的学术过渡连接词（如“一方面……；另一方面……；此外……”、“首先……；其次……；最后……”）组织为高密度、强逻辑的完整学术大段。

### 1.2 章节引言“黄金三段式”
各章开头引言（如 2.1、3.1、4.1）必须严格采用**结构紧凑的黄金三段式架构**，杜绝 5~6 段导致的段落碎片化：
1. **第一段（宏观背景、运动挑战与分层控制必要性）**：外骨骼运动增强背景、该场景生物力学高负荷挑战、步态时序相位在分层控制中的枢纽作用。
2. **第二段（传感技术横向对比与移动惯性技术瓶颈）**：对比压力鞋垫易损、sEMG 易受时变漂移干扰、光学动捕视距受限；论证大腿贴附式 MEMS IMU 优势，剖析三大核心难点（冲击去噪、STA伪影、时变自适应切片）。
3. **第三段（全章核心贡献与阶段架构概览）**：概括两阶段全链路架构，明确对后续控制规划章节的支撑作用。

### 1.3 “本章小结”编写准则
各章最后一节（如 2.4、3.4 等“本章小结”）必须严格遵循：
- **仅需一整段高密度总结（一段总结即可）**：彻底杜绝列出 (1) 至 (5) 类的分点列表，严禁段落碎片化；
- **全要素闭环覆盖**：该段总结必须高度涵盖全章感知去噪/模型/算法技术链路、关键离线或在线量化性能指标（如识别率、推理时延）、构建的标准数据/轨迹基准，并形成对下一章核心建模与控制任务的明确承上启下支撑。

## 2. 论文插图绘制、编号与目录归档规范 (Figure & Asset Standards)

### 2.1 规范图片命名与专属文件夹归档
- **统一规范编号命名**：所有用于论文中的图片必须规范编号并精炼命名，如 `图2-14a_标准爬楼髋关节屈伸角特性.png`、`图2-14b_标准爬楼屈伸角速度特性.png`、`图2-14_Camargo公开数据集标准爬楼示教曲线.png`。
- **必须放入规定的对应章节专属文件夹**：
  - 第二章图片放入 `论文图片\第二章论文图片\`；
  - 第三章图片放入 `论文图片\第三章论文图片\`；
  - 依此类推。**严禁将论文插图散落在根目录或混入无编号的临时测试图**。
- **写作目录环境净化**：
  - 写作目录（`论文攥写\`）必须保持纯净，**仅保留当前章节唯一的权威终稿 docx、原始底稿备份 docx 与对齐核验导出的 pdf**。
  - 严禁堆积历史过时草稿（如 21 段半成品旧版）、临时测试文档（`test_*.docx`）或 Word 临时锁文件（`~$*`）。

### 2.2 视觉与着色规范
- **文字颜色必须为纯黑色 (`#000000`)**：图内所有轴标签、刻度数字、图例、框内文字一律使用纯黑，严禁使用灰度或彩文字体。
- **图框严禁背景填充**：流程图与结构图中的矩形卡片、数据框体必须使用无填充透明背景（或纯白底），边框采用黑色实线或虚线（线宽 1.0 ~ 1.5 pt），严禁使用彩色填充底色。
- **高清晰度与坐标轴放大**：
  - 绘图分辨率必须达到 `dpi=350` 或更高（定稿建议 `dpi=600`）。
  - 刻度数字与坐标轴标题文字**保持在基准字号的 1.5 倍**（轴标题 12~13 pt，刻度与图例 10~11 pt），确保缩放嵌入后清晰锐利。

### 2.3 流程图框体纯文本与防溢出铁律
- **框内彻底去除章节标号**：流程图、总体架构图内部框体只写精炼的中文功能名称（如“惯性数据采集”、“运动信号预处理”、“周期自适应切片”），**严禁在框体内标注章节编号（如 2.2.1、2.3.1 等）**，防止编号冗长挤爆边框。
- **文字严格置于框内（防溢出边距 $\ge 30\%$）**：框内文字排布必须严格水平与垂直居中，单行文字长度不得超过框宽的 70%，四周留足至少 30% 的充裕安全呼吸裕度。**文字严禁超出框格或接触边框**。
- **连接线避让安全**：跨阶段绕行连接箭头与折线必须留出充足的转折避让间距（拐角留空 $\ge 0.2$ 坐标单位），从目标框体边缘中点平滑进入，**严禁箭头穿刺、接触或遮挡框内文字**。

### 2.4 多指标分组柱状图与数字标注规则
- **分组柱状图杜绝小数字重叠与冗余**：多指标并排相邻细柱图（如 Precision、Recall、F1 并排柱），由于柱宽狭窄且数值高度接近，**严禁在每根细柱上方强行标注重复密集的小数字**，彻底杜绝横向文字粘连重叠与视觉重复。
- **依托清晰坐标轴网格展示**：多指标对比主要依托刻度严密的 $y$ 轴（如 2.5% 或 5% 步长）与浅灰虚线网格线进行视觉判读；具体数值在正文配对的混淆矩阵或规范三线统计表中清晰陈列。
- **单柱图允许清晰标注**：仅对柱宽充裕、间距分散的单指标模型对比柱状图（如各算法识别率对比图），允许在柱顶居中垂直偏移标注黑色加粗数字。

### 2.5 横向对比双子图严格尺寸对称
- **统一画布尺寸 (`pad_to_canvas`)**：横向并排的两个子图 `(a)` 与 `(b)`，必须在图像生成后通过中心补白统一为 **100% 完全相同的像素宽高**（如 2110 $\times$ 1420）。
- **Word 单元格尺寸严格一致**：在 Word 嵌入表格中，左右单元格内图片的 `extent` 必须指定完全相等的 `cx` 和 `cy`（如 `cx="2736000" cy="1841289"`），杜绝“一高一矮”、“一胖一瘦”的版面失衡。
- **Word 关系 ID (rId) 隔离保护**：向 Word 注入双子图 DrawingML 关系时，必须使用高位偏移 ID（如 `rId801`、`rId802`），防止被 MathType 动态公式批量编译时顺延覆盖，导致图片被重定向至错误图片。

### 2.6 物理真实性与解剖学约束
- **场景与人体物理贴合**：绘制人体穿戴与运动姿态时，脚底必须真实接触支撑面（如楼梯踏步踏面），身体重心理学连贯，严禁出现小人“悬空浮于阶梯上方”的虚假绘制。
- **骨骼连线与坐标系规范**：骨骼中心线（如股骨轴）必须绘制为干净中性的连续实线，**严禁在骨骼连线上绘制向下箭头**；坐标轴采用标准 3D 正交右手三面体。
- **图例防遮挡**：散点图、分类超平面图的图例必须置于图像顶部独立无数据的预留空白区，严禁遮挡任何数据簇、支持向量或方程卡片。
- **单页高度占比**：单张独立图片高度严格控制在论文**单页篇幅的 1/5 左右**（通常高度约 4.5 cm ~ 5.5 cm），避免单图侵占过多版面。

## 3. 数学公式与正文符号规范 (Equation & MathTab Standards)

### 3.1 100% MathType 原生 OLE 嵌入 (`Equation.DSMT4`)
- **零 LaTeX 源码/纯文本残留**：正文叙述中涉及到的一切物理变量、数学符号（如 $x_S, y_S, z_S, \{S\}, \{B\}, a_x^S(t), \theta_x(t), \omega_y^S(t), \Delta t, \alpha, H, W, \theta, f_c, x[n], h[n], \mu(\phi), \sigma(\phi), S_1 \sim S_4$ 等），必须 100% 转为原生 MathType 行内公式对象。严禁出现带下划线的 ASCII 字符串（如 `x_S`）或未编译的 LaTeX 代码（如 `\omega`）。
- **中括号转义规则**：由于 MathType TeX 转换快捷指令将方括号 `[` 视为内部定界符，所有含有方括号的行内公式在 TeX 字符串中必须写为 `\left[` 与 `\right]`（如 `$x\left[n\right]$`），防止 MathType 跳过转换。

### 3.2 变量说明段落防乱码与百分号规避准则
- **百分号规避铁律**：正文叙述中的百分比数值与步长（如 1% 步长、0% ~ 100% 范围），直接在正文中使用原生中文文本百分号，**严禁将 `%` 放入 TeX 切换源码 `$...$`（如 `$1\%$` 或 `$\phi=0\%$`）**，避免 TeX 注释字符引发 MathType 转换失效或生成空框、反斜杠乱码。
- **公式说明精简化与解耦**：独立公式包含完整函数形式（如 $\mathcal{D}_{\rm demo} = \{ (\phi_i, \bar{\theta}(\phi_i), \sigma_\theta(\phi_i), \dot{\bar{\theta}}(\phi_i)) \}$）后，正文变量说明只对独立物理符号（如 $\phi_i$、$i$、$\bar{\theta}$、$\dot{\bar{\theta}}$、$\sigma_\theta$）进行 MathType 行内编译，避免行内堆砌多层嵌套重音符、四点省略号，杜绝基线错位与跨页断裂。

### 3.3 独立公式格式（MathTab 黄金标准）
每个独立编号公式必须严格按照以下四要素配置 Word 段落：
1. **版心尺寸基准**：页面左右页边距各设为 **2.50 cm**（A4 纸宽度 21.0 cm，版心宽度精准为 **16.00 cm** = 9074 dxa）。
2. **段落缩进绝对归零**：公式段落显式声明 `w:firstLine="0"`, `w:firstLineChars="0"`, `w:left="0"`, `w:right="0"`，**严禁继承正文的 2 字符首行缩进**。
3. **MathTab 双制表位精确定位**：
   - 第一制表位（公式居中）：`w:tab w:val="center" w:pos="4540"`（正中 8.01 cm）；
   - 第二制表位（编号贴右）：`w:tab w:val="right" w:pos="9080"`（右缘 16.02 cm）；
   - 段落内容布局：`\t[MathType公式OLE]\t(章-式号)`。
4. **垂直间距紧凑化与防裁切保护**：
   - 段落行距强制设置为“最小值 22 磅”（`w:spacing w:line="440" w:lineRule="atLeast"`），**段前段后间距强制设为 0 磅**（`w:before="0" w:after="0"`）。
   - 彻底消除公式段落过大空旷间距，同时确保复杂高大分式、上下标绝不被裁切。

### 3.4 正文排版与半角空格清理规范
- **杜绝公式与汉字间的孤立半角空格**：正文叙述中所有 MathType 行内公式、数字、物理单位前后，一律剔除多余的半角空格（如 `在20 Hz以上`，严禁出现 `在   20 Hz   以上`；`采样频率为100 Hz`，严禁出现 `采样频率为 100 Hz `）。

## 4. 学术真实性与传感器配置规范 (Hardware & Domain Truth)

- **传感器硬件严禁虚构**：本研究系统硬件配置明确为**穿戴于双侧大腿外侧的 2 组 6 轴 IMU 惯性测量单元（3 轴加速度计 + 3 轴陀螺仪）**，型号 WT901。
- **关键规格参数**：采样频率统一配置为 **100 Hz**（$\Delta t = 0.01\ \mathrm{s}$），加速度量程 $\pm 16g$，角速度量程 $\pm 2000^\circ/\mathrm{s}$。
- **严禁臆造“9 轴 IMU”或“磁力计”**：室内建筑环境存在严重铁磁体干扰，本课题硬件未采用且算法未引入磁力计，文中绝对不可出现 9 轴 IMU 或地磁计描述。
- **穿戴试验结构归集**：物理外骨骼样机的穿戴测试、受试者步态对比与助力效果评估统一归集至**第 5 章**，前序章节专注于感知算法、滤波去噪、相位识别与示教提取。
- **主动确认原则**：任何未见于参考论文或实验方案中的具体参数（如滤波截止频率、采样率、窗口步长、网络层数超参数等），**必须主动向用户提问讨论确定**，严禁盲目臆测。

## 5. 撰写交付前检查清单 (Geshi Checklist)

在生成任何章节 Word 文档后，必须逐项自检：
- [ ] **编号场景核验**：正文中是否仅在特定三级标题（如 2.3.2）下作为核心大模块划分出现 `（1）`、`（2）`？全篇其余任何位置是否已 100% 清除 `（1）`、`（2）` 标记？
- [ ] **段落凝聚性核验**：本可一体化叙述的内容是否已合为整段？是否有碎片化的一句话段落？引言是否为黄金三段式？本章小结是否严格为 1 整段总结？
- [ ] **图片归集与编号核验**：图片是否已规范编号（如 `图2-14a_xxx.png`）？是否已放入对应章节专属文件夹（如 `论文图片\第二章论文图片\`）？写作目录是否已净化无杂乱测试/过时文档？
- [ ] **双子图对齐与 ID 隔离核验**：并排 `(a)`/`(b)` 图画布像素宽高是否 100% 完全相同？Word 嵌入表格中图片关系 ID 是否使用高位隔离 ID（如 `rId801`/`rId802`）避免显示错位？
- [ ] **公式排版与防乱码核验**：正文行内变量是否 100% 转为 MathType？正文中是否已消除 TeX `%` 注释符？独立公式制表位是否为 4540/9080、缩进为 0、行距为 `atLeast 440` 且段前段后为 **0 磅**？
- [ ] **硬件真实性核验**：是否严格保持“双侧大腿 2 组 6 轴 IMU（3 轴加速度计 + 3 轴陀螺仪）”？是否有任何 9 轴或磁力计臆造？
