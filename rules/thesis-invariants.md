# 毕业论文写作与排版全局不变性守则 (Thesis Writing Invariants)

在本项目（`d:\ai\参考文献（论文）`）中进行任何章节撰写、内容修改、图表绘制与公式排版时，**必须始终无条件遵循以下不可逾越的硬性准则**：

---

## 一、 数学公式与正文符号硬性准则 (Non-Negotiable)

1. **100% MathType 原生嵌入 (`Equation.DSMT4`)**：
   - 所有的独立数学公式与正文行内变量，**必须全部转换为原生的 MathType OLE 对象**，严禁在 Word 中保留纯文本或 LaTeX 代码。
2. **严禁正文出现原始 LaTeX 标记或下划线纯文本**：
   - 正文叙述中涉及到的一切物理变量、上下标（如 $x_S, y_S, z_S, \{S\}, \{B\}, a_x^S(t), \theta_x(t), \omega_y^S(t), \Delta t, \alpha, H, W, \theta, f_c, x[n], h[n], \mu(\phi), \sigma(\phi), S_1 \sim S_4$ 等），必须 100% 编译为 MathType 行内对象或规范斜体上下标。
   - 绝对不可出现诸如 `x_S`、`\omega_y^S(t)`、`\Delta t` 等未编译字符。
   - 含方括号的行内公式在 TeX 转换源中必须写为 `\left[` 与 `\right]`，防止与 MathType 切换快捷键发生定界符冲突。
3. **独立公式 MathTab 黄金标准与垂直间距紧凑化**：
   - 公式段落必须清除继承的 2 字符首行缩进（`firstLine="0"`, `left="0"`）。
   - 必须配置标准双制表位：居中制表符 `4540`（版心正中 8.01 cm）、右对齐制表符 `9080`（版心右边缘 16.02 cm）。
   - 必须配置行距为“最小值 22 磅”（`w:spacing w:line="440" w:lineRule="atLeast"`），**段前段后间距强制设为 0 磅**（`w:before="0" w:after="0"`），严禁使用固定行距裁切公式，杜绝公式段落过大空旷间距。
   - **公式上下相邻正文段落间距紧凑化铁律（以紧凑标准为准，严禁空旷大间距）**：公式上方的前序正文段落必须显式设置段后 0 磅（`w:after="0"`）、行距 22 磅；公式下方的后续正文段落（如“式中……”）必须显式设置段前 0 磅（`w:before="0"`）、行距最小值 22 磅，严禁在公式前后段落使用 1.5 倍行距或默认段后间距，彻底消除空旷断层。
4. **正文行内字符间距净化与百分号防乱码铁律**：
   - 正文叙述中所有 MathType 行内公式、数字、物理单位前后，一律剔除孤立的多余半角空格（如 `在20 Hz以上`，严禁出现 `在   20 Hz   以上`）。
   - 凡涉及百分比数值与步长（如 1% 步长、0% ~ 100% 范围），直接使用原生中文文本百分号，**严禁将 `%` 放入 TeX 定界符 `$...$` 中（如 `$1\%$` 或 `$\phi=0\%$`）**，避免 TeX 注释字符引发 MathType 解析异常产生空白框或乱码。
   - 独立公式包含完整函数形式后，正文说明仅对核心独立物理变量（如 $\phi_i$、$i$、$\bar{\theta}$、$\dot{\bar{\theta}}$、$\sigma_\theta$）进行 MathType 行内编译，避免行内嵌套复合函数导致基线错位、重音浮空或乱码。
5. **全篇括号一律采用英文半角括号 `( )` 铁律 (Non-Negotiable)**：
   - 全文正文叙述、图表标题、变量说明、时序子相位划分、三级标题技术模块编号、公式引用等所有括号，**100% 统一使用英文半角括号 `( )`**，绝对严禁出现中文全角括号 `（ ）`。

## 二、 科学插图生成、编号与归档硬性准则

1. **规范图片命名与专属文件夹归档**：
   - 所有论文插图**必须严格按照 `图X-Y_精炼名称.png` 规范编号**，子图统一标注 `图X-Ya_xxx.png` 与 `图X-Yb_xxx.png`。
   - **必须存入对应的章节专属文件夹**：第二章图片放入 `论文图片\第二章论文图片\`，第三章图片放入 `论文图片\第三章论文图片\`，严禁散落在根目录或混入未编号的临时测试图。
   - **写作目录（`论文攥写\`）纯净化**：仅保留权威正本 docx、不可变底稿备份 docx 与对齐核验导出的 pdf，严禁堆积历史过时草稿（如 21 段半成品旧版）、临时测试文档（`test_*.docx`）或 Word 临时锁文件（`~$*`）。
2. **插图严禁文字遮挡曲线与波峰（防遮挡留白铁律）**：
   - 图内所有文字、标注箭头与图例框（Legend Box），**绝对严禁遮挡或穿刺数据曲线、峰值与波谷**，必须确保主要波形 100% 完整展现。
   - 必须通过坐标轴范围扩展（如在波峰上方主动扩展 25% ~ 35% 量程留足“无数据纯净天空区”）或将图例置于低数据密度空白角，实现曲线与文字的绝对物理避让。
3. **字体标准统一为小五号 (9.0 pt) 与黑白框体**：
   - 图内所有文字字体颜色**必须为纯黑色 (`#000000`)**。
   - 字体族统一配置：中文标准 **宋体 (SimSun)**，西文与数字 **Times New Roman**，数学公式符号 **STIX**（`mathtext.fontset = 'stix'`）。
   - 字号严格统一为 **小五号 (9.0 pt)**（`FONT_SIZE = 9.0`），坐标轴刻度数字与图例微调为 8.5 ~ 9.0 pt，严禁字号过大侵占绘图空间造成视线拥挤。
   - 图框、卡片框体**严禁有任何背景填充颜色**（必须为纯白底或透明底）。
4. **100% 真实代码与参数驱动绘图**：
   - 论文中所有的时序波形图、频域响应图、特征提取散点图、极限环、决策超平面图及性能对比柱状图，**必须 100% 基于真实实验数据集与算法代码真实运行生成**，参数必须来源于真实执行输出，确保图表随算法调优或数据更新动态自洽更新，**绝对严禁使用预定既定数值或假数据占位图**。
5. **流程图框体纯文本与防溢出铁律**：
   - 流程图内部框体只写精炼功能名称，**严禁在框体内标注章节编号（如 2.2.1、2.3.1 等）**。
   - 框内文字必须严格居中，文字宽度不得超过框宽的 70%，四周留足至少 30% 安全呼吸间距，**文字严禁超出框格或接触边框**。
   - 跨阶段连接线与绕行箭头必须预留充足转折避让间距，**严禁穿刺或遮挡框内文字**。
6. **分组柱状图杜绝文字重叠与冗余**：
   - 多指标相邻分组柱状图（如 Precision/Recall/F1 并排细柱），**严禁在每根狭窄柱子上方强行标注重复密集的小数字**，杜绝字体重叠与视觉冗余，依托刻度严密的 $y$ 轴网格线展现；单指标对比图允许在柱顶清晰加粗标注。
7. **横向对比双子图严格尺寸对称与 ID 隔离**：
   - 横向并排的两个子图 `(a)` 与 `(b)`，必须在图像生成后通过补白统一为 **100% 完全相同的像素宽高**，并在 Word 嵌入表格中指定完全相等的图形 `extent`，杜绝尺寸失衡。
   - 向 Word 注入双子图 DrawingML 关系时，必须使用高位偏移 ID（如 `rId801`、`rId802`），防止被 MathType 动态批量公式编译时顺延覆盖，导致图片被重定向至错误图片。
8. **精简、防遮挡与物理真实性**：
   - 凡有数学/物理符号的数据**只标符号，不加多余中文字符**。
   - 骨骼中心线必须为中性连续实线，**严禁在骨骼连线上绘制向下箭头**；图例必须移至图像顶部独立无数据空白区，严禁遮挡散点或边界。
   - 涉及人体的姿态图，脚底必须真实接触台阶踏面，符合人体运动学与物理接触面，严禁悬空。
   - 单张图片高度控制在**单页论文篇幅的 1/5 左右**（约 4.5 ~ 5.5 cm），坐标轴与文字保持 1.5 倍基准大小，保证高清。
9. **图题格式与图下正文排版绝对一致铁律**：
   - **中文图题**：严格居中，五号字体（`w:sz="21"`），**常规不加粗**，段前 4 磅（`w:before="80"`），段后 2 磅（`w:after="40"`），单倍行距（`line="240" lineRule="auto"`），无缩进。
   - **英文图题**：必须独立成段，严格居中，五号字体（`w:sz="21"`），**常规不加粗**，Times New Roman，段前 0 磅，段后 6 磅（`w:after="120"`），单倍行距，无缩进。
   - **图下方正文说明段落**：首行缩进 2 字符（`firstLine="420"`），小四（`sz="24"`），行距 22 磅（`line="440"`），段前 0 磅，段后 0 磅，两端对齐。全篇所有图（包括图 2-1、图 2-13、图 2-14 等）严格按照此统一格式执行，严禁局部变体。

## 三、 段落架构、编号规范与学术凝聚性准则

1. **`(1)`、`(2)` 编号的使用限定（全篇一律英文括号）**：
   - **唯一允许场景**：`(1)`、`(2)` **仅允许在三级标题下**（如 2.3.2、3.2.1 等），在该三级标题**内容较多、较重要的情况下，用于对该小节进行宏观核心大技术模块的分割攥写**（如 `(1) xxx主要内容：……`、`(2) xxx主要内容：……`）。
   - **全篇其余位置绝对禁止出现 `(1)`、`(2)` 标记**：除上述特定三级标题大模块拆分外，在引言、正文分析、图表解析、公式说明、理由阐述、以及各章小结等正文中，一律严禁出现 `(1)`、`(2)`、`(3)` 标号。
2. **整段凝聚性原则（杜绝碎片化）**：
   - **能够用一整段进行攥写的，绝对不要拆成几段或单句小列表攥写**！
   - 严禁将本来连贯的学术逻辑（如多项依据、多步特征、多个子相位定义）拆成一句话一行的小段落。
   - 段内应依托严谨的学术过渡连接词（如“一方面……；另一方面……；此外……”、“首先……；其次……；最后……”）组织为高密度、强逻辑的完整学术大段。
3. **章节引言“黄金三段式”架构**：
   各章开头引言（如 2.1、3.1）必须严格采用**黄金三段式架构**，杜绝段落碎片化：
   - **第一段**：宏观背景、外骨骼运动场景高负荷挑战与步态相位分层控制枢纽作用；
   - **第二段**：传统传感手段缺陷对比，论证大腿贴附式 MEMS IMU 优势，并剖析三大工程难点（瞬态冲击去噪、STA 软组织伪影、时变自适应切片）；
   - **第三段**：本章技术方案与两阶段架构概括，阐明对后续章节的支撑关系。
4. **本章小结编写准则**：
   各章最后一节（如 2.4、3.4 等“本章小结”）：
   - **强制要求仅需一段整体总结（一段总结即可）**，彻底杜绝列出 (1) 至 (5) 类的分点列表。
   - 该段总结涵盖感知/去噪/模型/算法技术链路、关键量化指标、标准数据基准，并形成对下一章核心建模与控制任务的明确承上启下支撑。

## 四、 硬件设定真实性与试验归集原则

1. **传感器配置真实性**：
   - 本课题明确采用**位于双侧大腿外侧的 2 组 6 轴 IMU 惯性传感器（3 轴加速度计 + 3 轴陀螺仪）**，型号 WT901BLECL5.0，采样频率 100 Hz。
   - **绝对禁止随意臆造“9 轴 IMU”或“磁力计”**。
2. **整机穿戴试验归集**：
   - 物理外骨骼样机的整机穿戴测试、多受试者在不同工况下的在线对比试验以及人机协同助力效果评估，**统一归集至第 5 章系统级穿戴实验中集中展开**，前序章节专注于感知算法、去噪建模与理论离线评估。
3. **主动确认原则**：
   - 遇到任何不明确的实验参数、硬件规格或算法设定，**必须主动向用户提问讨论确定，切勿盲目自定**。
